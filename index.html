How to LOGG

Meetings

1. Tap Start Meeting LOGG, name the meeting and inform participants.

2. Leave LOGG open while the meeting runs. The screen is kept awake during active listening.

3. Finish LOGG to create Summary, Decisions, Actions, Open Questions and Meeting Notes.

4. Export the result to Word or PDF when needed.

Quick Notes

Open Quick Notes to type or dictate. Use LIST or TODO for fast structured notes. Notes are saved locally and can be exported to Word, PDF or JSON.

Security status

SECURITY PASS PENDING

LOGG is currently a pilot. Speech is processed through Google Cloud Speech-to-Text in the EU. LOGG does not retain an audio recording.

The current Cloud Run speech endpoint is still publicly reachable and does not yet require user authentication. Saved meeting and note text is stored locally in the browser and is not yet protected by a LOGG encrypted vault.

Until the next security pass is completed: use LOGG for testing and non-sensitive meetings. Do not use it for confidential management, HR, financial, contractual or similarly sensitive information.

Privacy

Always inform participants before using speech transcription. Pause or finish LOGG whenever transcription should stop.
